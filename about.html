毎朝、カードが届くまで

夜のうちに材料を集めてAIがカードを作り、ファイルにして置いておく。スマホはそのファイルを読むだけ、という作りです。

  1. GitHub（クラウド） 稼働中

    ① 平日の朝6時に自動で起動

    GitHub Actions が、月〜金の決まった時刻に scripts/generate.py を実行します。人が操作しなくても動きます。土日はお休みで、最新の金曜のカードが表示されます。出題分野と問題数は、設定画面で保存した config.json に従います。

    関連用語: ジョブスケジューリング、cron、バッチ処理

  2. ニュースサイト 稼働中

    ② RSSで記事を集める

    MONOist、ITmedia、@IT、Publickey、IPA、JPCERT/CC の7つの配信から、直近72時間の記事を集めます。過去7日のカードと同じ記事は除きます。

    関連用語: RSS、XML、HTTPS

  3. Anthropic（AIサービス） 稼働中

    ③ Claude がカードを作る

    候補の記事一覧を Claude API に送り、3本を選んで要約・工場目線・質問・クイズを作ってもらいます。返事の形（JSONスキーマ）を指定しているので、決まった形で返ってきます。

    関連用語: API、APIキー（認証）、構造化データ、従量課金

  4. GitHub（クラウド） 稼働中

    ④ JSONファイルとして保存

    data/2026-11-15.json のように1日1ファイルで保存し、日付の一覧 data/index.json も更新します。データベースは使わず、ファイルだけで済ませています。

    関連用語: JSON、ファイル編成、バージョン管理（Git）

  5. GitHub（クラウド） 稼働中

    ⑤ GitHub Pages が配信

    画面のファイル（HTML・CSS・JavaScript）とJSONを、そのままWebで公開します。中身を計算するサーバーはなく、ファイルを渡すだけです。

    関連用語: 静的サイト、Webサーバ、CDN

  6. あなたのスマホ 稼働中

    ⑥ ブラウザで表示、回答は端末に保存

    app.js がJSONを読んでカードを組み立てます。クイズの回答はブラウザの localStorage に保存し、どこにも送信しません。ホーム画面に追加するとアプリのように使えます（ステップ4）。

    関連用語: クライアントサイド処理、Webストレージ、PWA

どこに何が置かれているか

置き場所置いてあるもの
GitHubプログラム、毎日のJSON、出題の設定（config.json）、APIキー（Secretsに暗号化して保管）
AnthropicAIモデル本体。呼ばれたときだけ動く
スマホクイズの回答記録と、設定を保存するためのGitHubのトークン

🔒 スマホからAIを直接呼ぶことはありません。APIキーはGitHubの中だけにあり、スマホやWebページには出てきません。スマホにあるGitHubのトークンは、このリポジトリの書き換えだけに権限を絞っています。

なぜこの作りにしたか

  • まとめて作り置き（バッチ処理）
    開くたびにAIを呼ぶと、待ち時間と費用がかかります。1日1回だけ作れば、画面はすぐ開き、費用も一定です。
  • 自分でサーバーを持たない
    GitHub Actions と Pages は無料枠で使えます。サーバーの保守やOS更新の手間がなく、かかるのはAPI代だけです。
  • データベースを使わない
    1日3枚程度ならJSONファイルで十分です。中身を人が読めて、Gitで変更履歴も残ります。

かかる費用

1回の生成（3問）で約0.11〜0.12ドル（入力 約7,600 ＋ 出力 約4,000トークン）。平日だけ作るので、月350円前後です。料金はAIが読んだ量と書いた量（トークン数）で決まり、アプリを開いたかどうかには関係ありません。
